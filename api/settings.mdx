---
title: "Flashcard Settings API: Read and Update Configuration"
sidebarTitle: "Settings"
description: "GET and PATCH /api/v1/flashcard-settings to read and update global spaced-repetition scheduler settings: learning steps and review intervals."
---

The settings endpoints let you read and update the global flashcard scheduler configuration that controls how Blue Accademy's spaced-repetition algorithm behaves across all your decks. You can tune how many new cards you see each day, how long cards stay in the learning queue before graduating to long-term review, and the intervals assigned when you rate a card as Easy.

---

## GET /flashcard-settings

Retrieve the current global scheduler settings.

```bash
curl http://localhost:8000/api/v1/flashcard-settings
```

### Response fields

<ResponseField name="id" type="integer" required>
  The unique identifier of the settings record. There is always exactly one settings record in the system.
</ResponseField>

<ResponseField name="newCardsPerDay" type="integer" required>
  The maximum number of new (never-seen) cards shown to you per day, summed across all decks. Once this limit is reached for the day, only learning and review cards will be shown.
</ResponseField>

<ResponseField name="learningSteps" type="string" required>
  A space-separated list of time delays applied to cards that are still being learned for the first time — for example, `"10m 1d 3d"`. A correct answer on each step advances the card to the next delay. After the final step the card graduates to Review state.

  **Time format:**
  - `Nm` — N minutes (e.g. `10m`)
  - `Nh` — N hours (e.g. `4h`)
  - `Nd` — N days (e.g. `3d`)
</ResponseField>

<ResponseField name="relearningSteps" type="string" required>
  A space-separated list of time delays applied to cards that have lapsed back into relearning after being rated **Blackout** during a review session. Uses the same time format as `learningSteps`.
</ResponseField>

<ResponseField name="minimumInterval" type="integer" required>
  The smallest allowed review interval in days. The scheduler will never schedule a review card sooner than this many days in the future, even if the algorithm would otherwise compute a shorter interval.
</ResponseField>

<ResponseField name="easyReviewInterval" type="integer" required>
  The interval in days assigned when you rate a card **Easy** while it is still in the learning queue. Instead of progressing through the remaining learning steps, the card skips directly into Review state with this interval.
</ResponseField>

<ResponseField name="normalReviewInterval" type="integer" required>
  The first long-term review interval in days assigned when a card successfully completes all its learning steps and graduates to Review state under a normal (Good) rating.
</ResponseField>

### Example response

```json
{
  "id": 1,
  "newCardsPerDay": 20,
  "learningSteps": "10m 1d 3d",
  "relearningSteps": "10m",
  "minimumInterval": 1,
  "easyReviewInterval": 4,
  "normalReviewInterval": 1
}
```

---

## PATCH /flashcard-settings

Update one or more scheduler settings. The request body must include all configurable fields.

### Request body

<ParamField body="newCardsPerDay" type="integer" required>
  Maximum new cards to show per day across all decks. Must be between `0` and `999` (inclusive). Set to `0` to pause new card introduction entirely.
</ParamField>

<ParamField body="learningSteps" type="string" required>
  Space-separated time delays for the learning queue, such as `"10m 1d"`. Accepts values in minutes (`m`), hours (`h`), or days (`d`).
</ParamField>

<ParamField body="relearningSteps" type="string" required>
  Space-separated time delays for cards re-entering the learning queue after a lapse. Uses the same format as `learningSteps`.
</ParamField>

<ParamField body="minimumInterval" type="integer" required>
  Smallest allowed review interval in days. Must be `1` or greater.
</ParamField>

<ParamField body="easyReviewInterval" type="integer" required>
  Review interval in days when a learning card is rated Easy and skips ahead to Review state. Must be `1` or greater.
</ParamField>

<ParamField body="normalReviewInterval" type="integer" required>
  First long-term review interval in days when a card graduates from the learning queue to Review state. Must be `1` or greater.
</ParamField>

### Example request

```bash
curl -X PATCH http://localhost:8000/api/v1/flashcard-settings \
  -H "Content-Type: application/json" \
  -d '{
    "newCardsPerDay": 20,
    "learningSteps": "10m 1d",
    "relearningSteps": "10m",
    "minimumInterval": 1,
    "easyReviewInterval": 4,
    "normalReviewInterval": 1
  }'
```

### Response

Returns the full updated settings object in the same shape as the GET response.

```json
{
  "id": 1,
  "newCardsPerDay": 20,
  "learningSteps": "10m 1d",
  "relearningSteps": "10m",
  "minimumInterval": 1,
  "easyReviewInterval": 4,
  "normalReviewInterval": 1
}
```

<Note>
  Scheduler settings apply **globally** to all decks. There is currently no per-deck scheduling configuration. Any change you make here immediately affects the review algorithm for every deck in your account.
</Note>
