The Decks API is the core of Blue Accademy's content model. A deck is a named collection of flashcards organised around a topic or learning track (such as `kubernetes`, `docker`, or `pulumi`). These endpoints let you create and manage decks, add flashcards to them, inspect study statistics, and fetch the cards that are due for review in the current session.

All paths below are relative to the base URL `http://localhost:8000/api/v1`.

---

### GET /decks

List all decks. You can optionally filter by track using the `track` query parameter.

<ParamField query="track" type="string">
  Filter results to decks that belong to a specific track (e.g. `kubernetes`,
  `docker`, `pulumi`). Omit this parameter to return all decks.
</ParamField>

```bash
# List all decks
curl http://localhost:8000/api/v1/decks

# Filter by track
curl "http://localhost:8000/api/v1/decks?track=kubernetes"
```

**Response — `200 OK`**

```json
[
  {
    "id": 1,
    "title": "Kubernetes Core Concepts",
    "description": "Pods, Deployments, Services, and more.",
    "track": "kubernetes",
    "cardCount": 42
  },
  {
    "id": 2,
    "title": "Docker Fundamentals",
    "description": "",
    "track": "docker",
    "cardCount": 18
  }
]
```

<ResponseField name="id" type="integer">
  Unique identifier for the deck.
</ResponseField>
<ResponseField name="title" type="string">
  Human-readable deck title.
</ResponseField>
<ResponseField name="description" type="string">
  Optional description for the deck. Defaults to an empty string.
</ResponseField>
<ResponseField name="track" type="string">
  The learning track this deck belongs to (e.g. `kubernetes`, `docker`,
  `pulumi`).
</ResponseField>
<ResponseField name="cardCount" type="integer">
  Total number of flashcards currently in the deck.
</ResponseField>

### POST /decks

Create a new deck. You must supply a `title` and a `track`. The `description` field is optional.

```bash
curl -X POST http://localhost:8000/api/v1/decks \
  -H "Content-Type: application/json" \
  -d '{
    "title": "My Deck",
    "description": "Optional description",
    "track": "kubernetes"
  }'
```

**Request body**

<ParamField body="title" type="string" required>
  The display name for the new deck.
</ParamField>
<ParamField body="description" type="string">
  An optional description. Defaults to an empty string if omitted.
</ParamField>
<ParamField body="track" type="string" required>
  The learning track to associate with this deck (e.g. `kubernetes`, `docker`,
  `pulumi`).
</ParamField>

**Response — `201 Created`**

```json
{
  "id": 3,
  "title": "My Deck",
  "description": "Optional description",
  "track": "kubernetes",
  "cardCount": 0
}
```

### PATCH /decks/{deck_id}

Rename an existing deck. Only the `title` field can be changed with this endpoint.

<ParamField path="deck_id" type="integer" required>
  The unique identifier of the deck to rename.
</ParamField>
<ParamField body="title" type="string" required>
  The new title for the deck.
</ParamField>

```bash
curl -X PATCH http://localhost:8000/api/v1/decks/1 \
  -H "Content-Type: application/json" \
  -d '{ "title": "Kubernetes Advanced" }'
```

**Response — `200 OK`**

```json
{
  "id": 1,
  "title": "Kubernetes Advanced",
  "description": "Pods, Deployments, Services, and more.",
  "track": "kubernetes",
  "cardCount": 42
}
```

### PATCH /decks/{deck_id}/track

Update the learning track tag on a deck. Use this to re-categorise a deck after creation.

<ParamField path="deck_id" type="integer" required>
  The unique identifier of the deck to update.
</ParamField>
<ParamField body="track" type="string" required>
  The new track value (e.g. `docker`, `pulumi`).
</ParamField>

```bash
curl -X PATCH http://localhost:8000/api/v1/decks/1/track \
  -H "Content-Type: application/json" \
  -d '{ "track": "docker" }'
```

**Response — `200 OK`**

```json
{
  "id": 1,
  "title": "Kubernetes Advanced",
  "description": "Pods, Deployments, Services, and more.",
  "track": "docker",
  "cardCount": 42
}
```

### DELETE /decks/{deck_id}

Permanently delete a deck and all of the flashcards it contains. This action cannot be undone.

<ParamField path="deck_id" type="integer" required>
  The unique identifier of the deck to delete.
</ParamField>

```bash
curl -X DELETE http://localhost:8000/api/v1/decks/1
```

**Response — `200 OK`**

```json
{
  "deleted": true
}
```

<Warning>
  Deleting a deck also deletes every flashcard and all associated review
  progress records within that deck. This operation is irreversible.
</Warning>

### GET /decks/{deck_id}/stats

Get study statistics for a deck. The response breaks down the card population into actionable counts your UI or scripts can use to track learning progress.

<ParamField path="deck_id" type="integer" required>
  The unique identifier of the deck.
</ParamField>

```bash
curl http://localhost:8000/api/v1/decks/1/stats
```

**Response — `200 OK`**

```json
{
  "total": 42,
  "mastered": 10,
  "available_to_study": 32,
  "newAvailable": 8,
  "learnDue": 5,
  "reviewDue": 19,
  "seenCount": 34
}
```

<ResponseField name="total" type="integer">
  Total number of flashcards in the deck.
</ResponseField>
<ResponseField name="mastered" type="integer">
  Cards that have been successfully learned and are no longer due soon.
</ResponseField>
<ResponseField name="available_to_study" type="integer">
  Cards available to study right now (new + learn + review combined).
</ResponseField>
<ResponseField name="newAvailable" type="integer">
  New cards remaining in today's daily limit.
</ResponseField>
<ResponseField name="learnDue" type="integer">
  Cards currently in the learning or re-learning queue that are due.
</ResponseField>
<ResponseField name="reviewDue" type="integer">
  Mature cards in the review queue that are due today.
</ResponseField>
<ResponseField name="seenCount" type="integer">
  Total number of cards you have seen at least once.
</ResponseField>

### GET /decks/{deck_id}/cards

List all flashcards in a deck, regardless of their review state.

<ParamField path="deck_id" type="integer" required>
  The unique identifier of the deck.
</ParamField>

```bash
curl http://localhost:8000/api/v1/decks/1/cards
```

**Response — `200 OK`**

```json
[
  {
    "id": 101,
    "deckId": 1,
    "front": "What is a Pod?",
    "back": "The smallest deployable unit in Kubernetes.",
    "codeExample": "kubectl get pods",
    "difficulty": "medium",
    "tags": "[]"
  }
]
```

<ResponseField name="id" type="integer">
  Unique identifier of the flashcard.
</ResponseField>
<ResponseField name="deckId" type="integer">
  ID of the deck that owns this card.
</ResponseField>
<ResponseField name="front" type="string">
  The question or prompt shown on the front of the card.
</ResponseField>
<ResponseField name="back" type="string">
  The answer or explanation shown on the back of the card.
</ResponseField>
<ResponseField name="codeExample" type="string | null">
  An optional code snippet displayed alongside the card. `null` if not set.
</ResponseField>
<ResponseField name="difficulty" type="string">
  Card difficulty hint — defaults to `"medium"`.
</ResponseField>
<ResponseField name="tags" type="string">
  JSON-encoded array of tag strings. Defaults to `"[]"`.
</ResponseField>

### POST /decks/{deck_id}/cards

Add a new flashcard to an existing deck. The `front` and `back` fields are required. You may optionally include a code snippet.

<ParamField path="deck_id" type="integer" required>
  The unique identifier of the deck to add the card to.
</ParamField>
<ParamField body="front" type="string" required>
  The question or prompt for the front of the card.
</ParamField>
<ParamField body="back" type="string" required>
  The answer or explanation for the back of the card.
</ParamField>
<ParamField body="codeExample" type="string">
  Optional code snippet to display with the card (e.g. a `kubectl` command).
</ParamField>
<ParamField body="difficulty" type="string">
  Difficulty hint. Defaults to `"medium"`.
</ParamField>
<ParamField body="tags" type="string">
  JSON-encoded array of tag strings. Defaults to `"[]"`.
</ParamField>

```bash
curl -X POST http://localhost:8000/api/v1/decks/1/cards \
  -H "Content-Type: application/json" \
  -d '{
    "front": "What is a Pod?",
    "back": "Smallest deployable unit in Kubernetes.",
    "codeExample": "kubectl get pods"
  }'
```

**Response — `201 Created`**

```json
{
  "id": 101,
  "deckId": 1,
  "front": "What is a Pod?",
  "back": "Smallest deployable unit in Kubernetes.",
  "codeExample": "kubectl get pods",
  "difficulty": "medium",
  "tags": "[]"
}
```

### GET /decks/{deck_id}/due

Fetch the cards that are due for review in the current session. The response extends the standard flashcard object with a `queue` field that tells you which queue the card came from so the UI can render it appropriately.

<ParamField path="deck_id" type="integer" required>
  The unique identifier of the deck.
</ParamField>

```bash
curl http://localhost:8000/api/v1/decks/1/due
```

**Response — `200 OK`**

```json
[
  {
    "id": 101,
    "deckId": 1,
    "front": "What is a Pod?",
    "back": "Smallest deployable unit in Kubernetes.",
    "codeExample": "kubectl get pods",
    "difficulty": "medium",
    "tags": "[]",
    "queue": "new"
  },
  {
    "id": 88,
    "deckId": 1,
    "front": "What does a ReplicaSet do?",
    "back": "Ensures a specified number of pod replicas are running.",
    "codeExample": null,
    "difficulty": "medium",
    "tags": "[]",
    "queue": "due"
  }
]
```

<ResponseField name="queue" type="string">
  Indicates which scheduler queue the card is coming from. One of:

  <Expandable title="Queue values">
    - `"new"` — the card has never been reviewed before.
    - `"learn"` — the card is in the active learning or re-learning step sequence.
    - `"due"` — the card is a mature review card whose interval has elapsed.
  </Expandable>
</ResponseField>

<Tip>
  Use the `queue` field to style the review UI differently for new cards versus
  cards already in rotation — for example, showing a special badge for brand-new
  cards.
</Tip>
