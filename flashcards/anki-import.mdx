If you already have a library of flashcards in Anki, you do not need to recreate them by hand. Blue Accademy can import cards directly from Anki's plain-text export format. You can import into an existing deck or have Blue Accademy create a new deck during the import — all from a single panel without leaving the Flashcards page.

## What you can import

Blue Accademy accepts Anki's **tab-separated text export** format. Each line in the file represents one card, with the front (question) and back (answer) separated by a tab character. Comment lines starting with `#` are skipped, as are blank lines.

```text
# This is a comment — it will be ignored
What is a Pod?	Smallest deployable unit in Kubernetes. Wraps one or more containers.
What is a Deployment?	Manages ReplicaSets to maintain desired Pod count. Supports rolling updates.
```

## How to export from Anki

1. In the Anki desktop app, go to **File → Export**.
2. Set the export format to **Notes in Plain Text (.txt)**.
3. Uncheck **Include HTML and media references** if you want clean, readable text without HTML tags.
4. Choose the deck or note type you want to export.
5. Click **Export** and save the `.txt` file to your computer.

## Import steps

<Steps>
  <Step title="Open the Import panel">
    Click the **upload icon** (↑) in the deck list header to open the Anki Import panel.
  </Step>

  <Step title="Choose or create a target deck">
    Select an existing deck from the **Target deck** dropdown. If you want to create a new deck during the import, check **Create new deck** and enter a name for it.
  </Step>

  <Step title="Upload a file or paste content">
    You have two options:

    - **Upload a file** — Click **Choose .txt file** and select the exported `.txt` file from your computer.
    - **Paste directly** — Paste the tab-separated content into the text area. Useful for small sets of cards or quick one-off imports.

    Both methods accept the same format.
  </Step>

  <Step title="Review the card count preview">
    As soon as content is detected, the panel shows a count of how many cards were found, for example **14 cards detected**. Use this to confirm the content was parsed as expected before importing.
  </Step>

  <Step title="Click Import">
    Click **Import N Cards** (where N is the number of detected cards). The button is disabled until a target deck and valid content are both present.
  </Step>

  <Step title="Check the result banner">
    After the import completes, a result banner appears showing how many cards were successfully imported and how many lines produced errors. If there were errors, the banner lists the problematic lines so you can correct them.
  </Step>
</Steps>

## Example format

```text
# Kubernetes basics
What is a Pod?	Smallest deployable unit in Kubernetes. Wraps one or more containers.
What is a Deployment?	Manages ReplicaSets to maintain desired Pod count. Supports rolling updates.
What is a Namespace?	A virtual cluster within a Kubernetes cluster used to isolate resources.
What does kubectl get pods do?	Lists all pods in the current namespace.
```

<Note>
  Lines starting with `#` are treated as comments and are skipped entirely during import. Blank lines are also ignored. Neither comments nor blank lines count toward the detected card total or the error count.
</Note>

## Custom separator

The default field separator is a tab character (`\t`), which matches Anki's default plain-text export. If your source file uses a different separator character, you can specify it by entering a single character as the custom separator when pasting content directly into the import panel.

<Warning>
  If a line cannot be parsed — for example because the tab separator is missing or the line contains only one field — it is counted as an error and skipped. The import continues processing all remaining valid lines, so a single malformed line does not cancel the entire import. Review the error details in the result banner and correct any affected lines before re-importing them.
</Warning>
