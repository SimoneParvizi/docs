This page is the status boundary for the docs site.

If you find code, routes, or partial UI for a feature but this page marks that area as unsupported, document the status here rather than the existence of unfinished code.

## Supported now

The current supported slice is flashcards.

That includes:

- Deck create, edit, and delete
- Flashcard study and review flow
- Persistence through the Python backend
- Repo-managed starter content
- Custom card creation
- Plain-text Anki import
- Flashcard settings

## In progress

These areas are being worked on but should not be presented as stable:

- Guided terminal exercises

## Not yet supported

These areas are not yet open or supported:

- CKAD-style validation flows
- Broader end-to-end or real-environment labs
- Chat
- Hosted sandbox orchestration
